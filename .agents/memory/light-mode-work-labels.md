---
name: Light-mode work labels
description: The user’s readability preference for Selected Work card metadata in light mode.
---

Light-mode Selected Work metadata should use a fully opaque pale-lavender label surface with dark violet text. Do not rely on translucent glass over the artwork for this state.

**Why:** the artwork underneath can make translucent labels feel unclear even when a contrast sample passes; the user explicitly preferred a solid silhouette that keeps the title readable.

**How to apply:** preserve the solid label treatment when adjusting Selected Work card styling or adding related light-mode card metadata.
